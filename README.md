# Easy Phone

A large-button Android contacts and dialer companion designed for older adults.

## Features
- Large contact photo cards in a two-column layout.
- Xiaomi Phone-inspired navigation: Favorites, Recents, Contacts and Keypad.
- Search contacts and launch the system dialer with a selected number.
- Large numeric keypad.
- Add contacts using Android's Contacts app.
- English interface.

## Build
Push to `main` or run **Build Easy Phone APK** from GitHub Actions. Download the `EasyPhone-APK` artifact.

## Notes
- The app requests Contacts permission to display names, numbers and contact photos.
- Tapping CALL opens Android's system dialer with the number filled in; the user confirms the call there.
- This first version is a companion dialer, not a replacement default-phone app or custom in-call screen.
- Contact photos are managed in the phone's Contacts app.
